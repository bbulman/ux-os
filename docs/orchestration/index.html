Orchestration

Proposed set: may be kept, renamed or dropped

Running the other sets against a real target until it meets a bar.

The other sets are methods. This one runs them against a real page and keeps going until it holds up.

What's missing: Only /crit works outside Workshopr.

crit and critique-partner

Interviews you about a page, then critiques it against your own written rules and loops until a verifier passes it.

Testing: A gate with 55 test cases, and two headless runs.

Needs Node 18 or later and Playwright with Chromium.

git clone https://github.com/bbulman/critique-partner.git
cd critique-partner && ./install.sh
Loads on its own

Design Agent

Testing: An independent critic scores every pass.

Runs only on Workshopr, so there is nothing to install.
