create-icon-system

Decides whether to adopt, curate or draw an icon set, then delivers a checked sprite, manifest and wrapper without quietly redrawing anything.

How to run it

Type it in Claude Code, or let Claude pick it on its own:

/ds-kit:create-icon-system

Install

The source is private for now, so there is nothing to install yet.

Testing

Final run, one case: 8 of 8 outcome checks with the skill, 8 of 8 without (15 of 15 with its own checks). 57s and $0.23 with, 53s and $0.16 without. No gain on outcomes alone; the gain is the contract and what it refuses to do. Trigger test 2 of 2.

Build story

Written from scratch.

What the no-skill run missed. It redrew one icon, deleted a detail from another, and left no manifest, licence or record of merged names.

What the skill adds. ds-icons allow-lists what can reach a sprite, refuses changes until a person rules on them, keeps merged names as aliases and fails any hand edit to the sprite or demo.
