## How it was built

Written from scratch on 10 November 2026 in our own words. It exists because only a proto run used to fill in which beliefs an excerpt bears on, so seeing what one interview changed meant rewriting a model. It marks the evidence and counts against the bar, and a fresh agent reads the marks cold.

It is the closest of the four to the `/proto-validate` Bill removed on 9 November. The difference is that it rewrites no model.

## What testing showed

Three interviews planted to contradict two beliefs the person was sure of came back led by exactly those two. A review found that excerpts taken in by any other command never got marked, so it now works through every excerpt still marked `none`, whichever run took it in.
