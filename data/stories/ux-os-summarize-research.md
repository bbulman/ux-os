## How it was built

Written from scratch on 9 November 2026 in our own words. Bill set the list of twelve research skills, which follows the topics in MC Dean's design-research pack. About 40 existing skills were reviewed for methods worth keeping and no text was carried over. A wording check found no run of 5 consecutive words shared with 83 plugin and repo skill files, which is why it carries no attribution.

It shares a common folder with the other eleven: the evidence tags, the intake for interviews, the checking script and the designed research book.

## What makes it different

Each finding is rated by how many people from different organisations stand behind it, and what cuts against it is always shown. Disagreement is reported rather than smoothed over. With no real data it stops, because a summary of beliefs is not a summary of research.

## What testing showed

The test was incomplete. On made-up data its draft passed the checking script, but a test agent was refused when it tried to write a file named `summary.md`, so the skill has not yet written its output. With no data it stopped and said what it needed.
