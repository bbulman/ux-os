## What it is for

Research ends in a decision, and nothing in the set kept it. This command adds one row to `decisions.md` in the idea folder: the decision, the evidence or belief it rests on, and what you would have to see to reverse it. The file is a log. Rows are added and never removed or reworded, and a reversed decision gets a new row that says which one it replaces.

## How it was built

Built on 12 November 2026, the same day as the folder map and the per-project, per-discipline folder layout. Bill asked for a project template of research files. The map came first, and it listed a decisions file as the one thing missing. Bill then asked for it.

- The basis of a decision is tagged like any other claim, so the existing pencil and ink rule applies without a new rule.
- Tags sit only in the Rests on column. The first version of the check accepted a tag in any cell, which an independent review caught.
- The check also holds each row to a real date that is not in the future and not earlier than the row above, numbering in order, a link on every first-party citation, and one verdict per belief across the folder.
- `status.mjs` reports how many decisions rest on pencil, and the map shows the same count.
