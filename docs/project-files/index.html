Project files

The files a project keeps, so the skills that read them start from the same facts: what the product is, who it is for, and how it should look, move and sound. Each one lists the skills and agents that read it.

One command

Sets up a project's nine UX-OS files (PRODUCT, DESIGN, AGENTS, PERSONAS, JOURNEYS, JTBD, taste, motion and VOICE) from annotated templates, writing only the ones that are missing.

Once, in Claude Code

/plugin marketplace add bbulman/ux-os
/plugin install ux-os@ux-os

Then, in each project

/ux-os:create-project-files
