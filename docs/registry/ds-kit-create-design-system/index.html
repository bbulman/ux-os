Install

The source is private for now, so there is nothing to install yet.

Testing

Final run, one case: 9 of 9 outcome checks with the skill, 8 of 9 without (20 of 20 with its own checks). 88s and $0.27 with, 38s and $0.17 without. A second case confirms it stops and asks when someone is there to answer. Trigger test 3 of 3.

Build story

Replaces the earlier ds-kit skill of this name, which needed a chosen direction to start from. Written from scratch, with no wording shared with the third-party design-systems pack.

What the no-skill run missed. It read stylesheets with curl, skipped one that was awkward, measured no contrast and counted nothing across pages.

What the skill adds. ds-extract measures computed styles across pages at several widths, rejects chat widgets and consent banners, and writes every conflict as a decision for a person. Independent review then found a page could steer it into writing outside its output folder or fetching internal addresses; both are closed.

Known limit. A server that answers the first check and then redirects the browser elsewhere cannot be fully prevented.
