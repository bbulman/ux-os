Jobs

What I hand to which skill in orchestration. All the jobs

  1. Set up a new project's files

    Pick create-project-files /ux-os:create-project-files BY NAMERuns when you type it

    Nine annotated templates, each saying what the file is for and who reads it. Writes only what is missing and asks three questions at most.

  2. Iterate a Workshopr page to a quality bar

    Pick Design Agent agent: design-agent:design-agent ONLoads on its own

    Designs, then an independent critic scores each pass, and it loops until the bar is met.

  3. Plan a new feature before building it

    Pick feature-plan agent: feature-plan:feature ONLoads on its own

    Looks everything up, asks one question at a time and writes a spec, a design brief and build slices.

  4. Build a planned feature slice

    Pick feature-build agent: feature-build:feature-build ONLoads on its own

    An independent reviewer scores every pass, and a gate holds it until tests, lint and the design system pass.

  5. Run someone else's skill and keep its claims honest

    Pick run /ux-os:run BY NAMERuns when you type it

    Runs a third-party skill unedited, files its claims as belief or evidence, and an auditor checks the citations.
