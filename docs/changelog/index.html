Changelog

What changed in UX-OS, newest first.

  1. 15 November 2026

    • Added the Loadout page: the plugins and settings that decide what Claude loads on my machine, as a block you can copy or download.
    • Added a quarterly prune report, scripts/prune.mjs, which lists third-party skills I have never used and that no job depends on, with the setting that would switch each one off.
    • Workflow steps are light cards on the paper instead of film-strip frames, and no longer show how often each skill has run.

  2. 14 November 2026

    • Rebuilt the site around one registry of skills, packs, agents, commands and tools, with Jobs, Workflows, Project files and a new Content set.
    • Whether each entry loads, runs by name or is off now comes from this machine's settings, not from a hand-typed list.
    • Usage comes from Claude Code transcripts, and most entries have never been used. Each entry page says how often.
    • Dropped customer-research, which is no longer installed. Corrected site-architecture, which I rewrote as my own on 9 November.
    • Added /ux-os:create-project-files and nine annotated project-file templates, with Workshopr's own files as worked examples.

  3. 13 November 2026

    • MC Dean's packs lead every set again. My information architecture, interaction design and strategy skills now run only by name.
    • ux-os 0.3.0: a service blueprint skill and a guide to the files a project keeps.

  4. 12 November 2026

    • ux-os 0.2.0: a decisions log, a folder map for each idea, and folders by discipline.
    • Added /ux-os:run, which runs a third-party skill and files its claims, and an auditor that checks them.

  5. 10 November 2026

    • The research skills became the ux-os plugin, installable from this repo.
    • ds-kit's final evals: 65 of 67 outcome checks with the skills, 50 of 67 without.

  6. 9 November 2026

    • Named UX-OS and published the first version of this site.
    • Split the information architecture skill into a front door and eleven focused skills.
    • Built eleven interaction design skills, ten strategy skills, twelve research skills and Design OS's eight stages.

  7. 24 October 2026

    • Built the first information architecture skill and tested it against no skill: 24 of 25 checks against 23.
