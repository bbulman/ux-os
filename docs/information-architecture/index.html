Information architecture

Content inventories, card sorts, taxonomies, labels, sitemaps, navigation, URL rules, content models, redirects, tree tests and findability.

Where things go decides whether anyone finds them. It's also the one set with a skill tested end to end.

What's missing: Nothing outstanding. In one run of the same three test cases, the split scored 28 of 29 and the single skill 25 of 29.

information-architecture

The front door for the set: scopes the job, holds the rules across it and routes to the eleven focused skills.

Testing: As one skill: 3 test cases, 3 rounds, every grade public. Latest round 28 of 29 with the skill, 19 of 29 without. Split into twelve: 28 of 29 in one run, against 25 for the single skill the same day.

This installs all twelve skills in the set.

git clone https://github.com/bbulman/information-architecture-skill.git
cd information-architecture-skill && ./install.sh
