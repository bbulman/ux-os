Build story

How it was built

Written on 9 November 2026, replacing stakeholder-alignment in MC Dean's ux-strategy pack, as one of ten. The writer did not read the old skill, and worked from coverage notes in other words, a baseline run, and research listed in references/evidence.md. No five-word phrase or heading is shared with the skills it replaces.

What testing showed

An independent agent wrote a sealed case for each skill. In round one the new skills scored 94 of 100 checks and no skill 95, and blind judges preferred no skill on 8 of 10, because the output read as analysis rather than the finished thing. Each skill was then changed to write the finished thing first, with its working in a separate file. On a rerun of the same cases the new skills scored 95 and no skill 94, and judges put the new skill first on 5 of 10. Full results are in the repo readme.
