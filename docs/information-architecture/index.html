Information architecture

Content inventories, card sorts, taxonomies, labels, sitemaps, navigation, URL rules, content models, redirects, tree tests and findability.

Where things go decides whether anyone finds them. It's also the one set with a skill tested end to end.

What's missing: Nothing outstanding. In one run of the same three test cases, the split scored 28 of 29 and the single skill 25 of 29.

Jobs

What I hand to which skill in information architecture. All the jobs

  1. Work out why people can't find things

    Pick findability /findability BY NAMERuns when you type it

    My most used IA skill. It traces each path a person would take and names where it breaks.

  2. Decide the page tree for a site

    Pick sitemaps /sitemaps BY NAMERuns when you type it

    Places every page, checks the tree agrees with itself and scales to the job.

    Rival create-sitemap writes the sitemap as a file for wireframes to build on, once the structure is decided.

  3. Plan or restructure a public website

    Pick site-architecture /site-architecture BY NAMERuns when you type it

    Pages, URLs, header, footer and links that lead a visitor to a decision. Beat the skill it replaced 31 to 26 of 32 checks.

  4. Design navigation

    Pick navigation /navigation BY NAMERuns when you type it

    Works from the content and the tasks, not from a list of menu patterns.

  5. Set URL rules or plan redirects

    Pick url-structure /url-structure BY NAMERuns when you type it

    Rules a whole site can follow, with a script that checks a list of URLs against them.

    Rival redirect-maps is the one to use once URLs are moving.

  6. Test a structure before building it

    Pick tree-tests /tree-tests BY NAMERuns when you type it

    Plans the tasks and reads the results of a tree test, so the labels are tested before the screens.
