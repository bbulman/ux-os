UX-OS / Accessibility and inclusion

Accessibility and inclusion

Proposed set: may be kept, renamed or dropped

Inclusive personas, cognitive access, accessible content and adaptive interfaces.

Access decided at the end gets cut. This set starts with who's being left out.

What's missing: Five of the six packs are switched off.

The @designer-skills commands below need this once.

/plugin marketplace add Owl-Listener/designer-skills

inclusive-personas

Personas, user stories and scenarios that include disability from the start.

/plugin install inclusive-personas@designer-skills
Loads on its own

accessibility-decisions

Documents and maintains accessibility decisions across teams and time.

/plugin install accessibility-decisions@designer-skills
Off

accessible-content

Content that works for screen readers, cognitive differences and diverse literacy.

/plugin install accessible-content@designer-skills
Off

adaptive-interfaces

Design systems that respect user preferences and adapt to individual needs.

/plugin install adaptive-interfaces@designer-skills
Off

cognitive-accessibility

Cognitive load, plain language, wayfinding and focus.

/plugin install cognitive-accessibility@designer-skills
Off

inclusive-interaction

Multi-modal interactions that adapt to how people move, perceive and communicate.

/plugin install inclusive-interaction@designer-skills
Off

The states are from my setup on 10 November 2026. Yours start from whatever you install.
