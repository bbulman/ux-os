UX-OS / Visual design

Visual design

Hierarchy, colour, type, layout, visual critique and page craft.

Hierarchy and type are where AI-made pages start to look alike. These give Claude a way to see that and correct it.

What's missing: Nothing of mine beyond landing-page-design.

The @designer-skills commands below need this once.

/plugin marketplace add Owl-Listener/designer-skills

ui-design

Skill pack by MC Dean

Colour, type scale, spacing, layout grid, responsive design, dark mode, visual hierarchy, platform conventions and the Gestalt laws.

/plugin install ui-design@designer-skills
Loads on its own

visual-critique

Skill pack by MC Dean

Critiques hierarchy, colour, typography, composition, affordance, information density and brand consistency.

/plugin install visual-critique@designer-skills
Loads on its own

impeccable

Skill by Paul Bakaus

Designs, critiques, audits, polishes and animates frontends.

npx skills add pbakaus/impeccable
Loads on its own

landing-page-design

Copy strategy and look before any code, a hero-first build, gates against generic AI pages and a two-reviewer feedback round.

Testing: One dry run and two critic passes. The UX-OS landing page went through it too.

Not published yet.

Loads on its own

Taste skills

Skill pack by Leonxlnx

Frontend taste skills. This repo holds design-taste-frontend, and the high-end, minimalist and brutalist styles now live in taste-skill-classics.

/plugin marketplace add Leonxlnx/taste-skill
/plugin install taste-skill@taste-skill
/plugin marketplace add Leonxlnx/taste-skill-classics
/plugin install taste-skill-classics@taste-skill-classics
Run by name
