create-ds-site

Generates a documentation site from the system's own files so it cannot disagree with them, and fails when it goes stale.

How to run it

Type it in Claude Code, or let Claude pick it on its own:

/ds-kit:create-ds-site

Install

The source is private for now, so there is nothing to install yet.

Testing

Final run, one case: 6 of 6 outcome checks with the skill, 5 of 6 without (11 of 11 with its own checks). 283s and $0.19 with, 87s and $0.28 without. Trigger test 2 of 2.

Build story

Written from scratch.

What the no-skill run missed. It wrote a sensible generator but never opened the site, had no search or staleness check, and only worked from inside the repo.

What the skill adds. ds-site builds from the sources, sandboxes demos, tests the phone menu and search in a browser, and fails on any drift. Independent review found injection paths through catalog and icon data; those are closed.

Known limit. A demo opened on its own can still run its own inline script.
