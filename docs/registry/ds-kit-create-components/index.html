How to run it

Type it in Claude Code, or let Claude pick it on its own:

/ds-kit:create-components

Install

The source is private for now, so there is nothing to install yet.

Testing

Final run, one case: 7 of 7 outcome checks with the skill, 6 of 7 without (12 of 12 with its own checks). 606s and $1.12 with, 40s and $0.14 without, the most expensive skill in the set. Trigger test 2 of 2.

Build story

Written from scratch.

What the no-skill run missed. Solid components, but no catalog, and a claim that everything worked from the keyboard in the same message that said nothing was tested.

What the skill adds. ds-catalog requires enumerated options, every state covered or excused, and option names consistent across the set. Entries stay draft until keys have actually been pressed in a browser.
