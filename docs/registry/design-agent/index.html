Build story

How it was built

First built on 16 October 2026 as version 1.1.0, and now at 1.6.0 (9 November 2026). It replaced Intent and its 16 sub-skills, ui-designer, ux-designer, designer, the design-system master agent and workshopr-uxdrift with one entry point. It drives impeccable for craft commands.

It frames the problem, designs or refines, then loops through critique, fix, re-render and re-score until an exit bar is met. An independent critic does the scoring, and each run ends by writing down what it learned.

The plugin's folder is gitignored, so its CHANGELOG.md is its only history.

There is a longer write-up, "Design Agent: what it does and how to run it".
