## How it was built

Written on 9 November 2026 to replace `gesture-patterns` in MC Dean's interaction-design pack, as part of a set of eleven. The writer did not read the old skill, and worked from a baseline run showing what the old skill missed, plus standards and research listed in `references/evidence.md`. A checking script compared it with 43,321 existing skill files: no five-word phrase or heading is shared with any design skill.

## What testing showed

The grading checks for this case were accidentally visible to the writer, so its score does not count as evidence. Back-swipe behaviour was measured in one iOS 26.5 Simulator run; iOS 27 API names come from Apple's documentation and were not compiled. The full results and every caveat are in the [repo readme](https://github.com/bbulman/interaction-design-skills).
