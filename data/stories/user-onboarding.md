## How it was built

Written on 9 November 2026 to replace `onboarding-design` in MC Dean's interaction-design pack, as part of a set of eleven. The writer did not read the old skill, and worked from a baseline run showing what the old skill missed, plus standards and research listed in `references/evidence.md`. A checking script compared it with 43,321 existing skill files: no five-word phrase or heading is shared with any design skill.

## What testing showed

The grading checks for this case were accidentally visible to the writer, so its score does not count as evidence. A third-party skill of the same name sits in the platform repository; a session there loads this one when it is called by name. The full results and every caveat are in the [repo readme](https://github.com/bbulman/interaction-design-skills).
