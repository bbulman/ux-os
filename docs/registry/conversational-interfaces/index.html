Build story

How it was built

Written on 9 November 2026 to replace conversational-ux in MC Dean's interaction-design pack, as part of a set of eleven. The writer did not read the old skill, and worked from a baseline run showing what the old skill missed, plus standards and research listed in references/evidence.md. A checking script compared it with 43,321 existing skill files: no five-word phrase or heading is shared with any design skill.

What testing showed

The full results and every caveat are in the repo readme. Across the six clean tests the new set tied the old pack on checks, 60 of 62 each. Blind judges ranked the new skill first on three and last on three: it catches more and makes fewer errors, but writes too much. An independent review then found 25 problems, all fixed. The final wording about length has not been tested.
